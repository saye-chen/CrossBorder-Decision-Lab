# 专业报告交付协议

正式交付按以下顺序，保证证据边界先于业务姿态：

1. **一句话结论**：CE 等级、estimand、效应区间、适用范围和最关键限制。
2. **决策问题**：owner、会改变的决定、阈值、最晚决策时间。
3. **识别合同**：潜在结果、DAG、调整集/分配机制、关键假设和替代解释。
4. **设计与协议**：单位、treatment、指标、样本、停止、多重性、偏差。
5. **数据质量**：assignment/exposure/outcome 对账、成熟、缺失、SRM、污染。
6. **估计与不确定性**：绝对/相对效应、区间、基线、单位、支持域。
7. **诊断与反证**：placebo、negative control、敏感性、替代规格、失败点。
8. **经济解释**：参数版本、增量利润区间、保本、下行风险；与 CE 分开。
9. **等级与动作上限**：允许/禁止措辞和动作，最终业务 owner 待决项。
10. **复现与失效**：哈希、版本、后端、review、recompute/invalidation trigger。

报告必须明确区分 confirmed fact、assumption、model output、expert judgment 和 unknown。若没有合格反事实，应写“平台归因/关联/预测”，不得写“由该动作带来”。如果区间同时覆盖有害与有价值区域，应写“精度不足、方向未决”，不能仅以 p>0.05 写“无效果”。
