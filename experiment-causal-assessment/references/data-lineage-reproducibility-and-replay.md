# 数据血缘、复现、重放与回滚

## 复现包

每次可消费分析绑定：协议与 amendments、原始/派生数据快照清单、字段合同、抽取查询或接口版本、转换 DAG、代码提交哈希、环境/依赖锁、运行参数、seed、后端及证明、结果对象、诊断、日志、异常和人工判断。

哈希使用 canonical JSON 或内容寻址；文件顺序、浮点序列化、时区和 locale 固定。时间字段使用 UTC RFC3339，并保留业务时区。随机性记录生成器、算法、seed 和并行策略；不能只写“已固定随机种子”。

## 数据成熟与血缘

assignment、exposure、outcome 独立记录并可对账。数据集保存 source、owner、授权范围、最小化、抽取时点、最大事件时间、迟到/回填政策、去重规则和质量断言。指标成熟前结果标 `provisional`，成熟或回填后触发重算。

## 失效与影响闭包

触发器包括：指标定义/代码/依赖/后端变化；源数据回填；assignment/exposure 修正；关键假设或 DAG 更新；经济参数过期；目标总体/平台/国家改变；发现污染、泄漏、SRM、并发干预或合规问题。

影响闭包从输入→派生数据→分析→handoff→消费者决定追踪。失效必须传播状态，不能仅在新报告中备注。回滚保留旧版本、原因和替代版本，不覆盖历史。

## Replay

重放分三层：

1. `structural_replay`：对象、哈希、依赖、状态和脚本可运行。
2. `deterministic_replay`：同输入/环境产生容差内同结果。
3. `decision_replay`：在历史可得信息截点重建当时判断，避免使用未来信息。

重放差异按 schema、数据、数值、随机、后端、环境和人工判断分类。未解释的实质差异阻断 CE5。
