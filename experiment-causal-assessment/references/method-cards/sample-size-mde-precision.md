# 方法卡：固定样本、MDE 与精度

- **目标**：在冻结 alpha、power、分配比、基线/方差、最小重要差异和流失下规划两臂固定样本。
- **连续/计数/ratio influence**：使用均值差正态规划公式；方差必须对应分析尺度或单位 influence function。
- **二元**：使用不等分配的两比例正态近似；alternative rate 必须位于 (0,1)。
- **输出**：每臂/总样本、公式版本、假设、attrition inflation；MDE 与 confidence half-width 分开。
- **敏感性**：必须跨合理基线/方差、流失、效应和分配比重算，不能只给单点。
- **不覆盖**：聚类设计效应、序贯、多重性和有限总体修正；这些必须在对应设计层增加。
- **决定语义**：样本规划是协议输入，不是效果证据；不显著且宽区间应写精度不足。
