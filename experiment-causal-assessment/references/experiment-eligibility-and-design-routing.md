# 实验资格与设计路由

## Q1–Q10 失败关闭

| Gate | 核心问题 | 失败处置 |
|---|---|---|
| Q1 可行动性 | 结果会改变哪一个真实决定？ | 停止或重写问题 |
| Q2 干预可定义 | treatment/对照是否可复制、可版本化？ | 阻断因果设计 |
| Q3 伦理与合规 | 风险、同意、公平、平台规则是否允许？ | 停止/升级审查 |
| Q4 分配与识别 | 随机化或准实验识别是否成立？ | 阻断 CE4/CE5 |
| Q5 单位与干扰 | 分配/分析单位、spillover 是否可控制？ | 改集群/网络设计或降级 |
| Q6 指标与时间 | 指标、成熟窗、归因窗、护栏是否冻结？ | 不启动 |
| Q7 样本与精度 | 能否达到最小重要差异或目标精度？ | 缩小问题/延长/不做 |
| Q8 数据可审计 | assignment、exposure、outcome、血缘可追踪？ | 不启动或 CE0–CE3 |
| Q9 停止与多重性 | 是否预定停止、looks、家族和偏差规则？ | 固定后再启动 |
| Q10 经济合理性 | 信息价值是否覆盖成本、延迟和伤害？ | 不做或最小化 |

Gate 状态使用 `pass/fail/unknown/not_applicable/conflict`。Q2、Q3、Q4、Q5、Q6、Q8、Q9 的 `fail/unknown/conflict` 默认阻断 CE4/CE5；`not_applicable` 必须有字段规则和理由。

## 设计路由

1. **个体随机**：优先；适用于处理可在个体隔离且干扰可忽略。
2. **分层/区组随机**：关键预处理变量影响结局或样本较小时使用；分析匹配设计。
3. **集群随机**：处理只能簇级实施或个体污染严重；必须考虑 ICC、簇数、大小不等和簇级自由度。
4. **Geo/holdout**：媒体或区域动作；先冻结 geo 匹配、spillover、预拟合和随机化分布。
5. **Switchback**：共享供给、市场或平台时间切换；处理周期、washout、carryover、周期性和序列相关。
6. **自然/准实验**：只有明确制度、阈值、时间或对照机制时选择 DiD/RDD/IV/SCM。
7. **观察性因果**：写 target trial、DAG、overlap、cross-fitting、敏感性；不能只“控制协变量”。
8. **非因果**：识别失败时诚实输出 CE0–CE3 与下一步实验。

## 能力档

- `native_executable`：仓内独立验证的确定性实现，具有解析、模拟、parity、对抗和 mutation 证据。
- `verified_backend`：调用成熟后端；锁定版本、方法选项、输入输出、seed、容差、parity 和失败语义。
- `protocol_only`：仅生成识别与分析合同，必须交由具资质方法团队执行。
- `research_only`：研究候选，不进入常规业务决定。

能力档描述“仓库能否可靠执行”，不描述方法在学术上的高低。后端失效绝不改为隐式 native 近似。

## 路由冲突

当多个设计可行时，以最小识别假设、最强可执行性和最低干扰为优先，同时比较成本、统计精度和外部有效性。存在冲突时记录备选、拒绝理由和 sensitivity 路线；不得只因预期更容易显著而选方法。
