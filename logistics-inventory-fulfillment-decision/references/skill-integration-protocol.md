# LIFD 跨 Skill 集成协议

## 共享包

交接必须包含 `packet_id/source_skill/source_runtime/target_skill/object_id/object_version/as_of_time/status/evidence_ids/calculation_ids/allowed_uses/forbidden_uses/expiry/recompute_trigger`，物流对象还必须包含 SKU/批次、货权、国家、仓/路线、单位、数量状态、承诺窗和能力版本。

`allowed_uses/forbidden_uses` 分别记录允许用途与禁止用途；任何下游计算都必须在允许用途内。

## 双向主权

| 对接域 | LIFD 可消费 | LIFD 可返回 | 禁止越权 |
|---|---|---|---|
| CIDM | 资本姿态、现金和利润红线 | 网络可行性、全成本、容量、退出成本 | 改写资本进入/退出 |
| CIM | 已确认供应/配送/竞争事件 | 受影响路线、库存和恢复需求 | 推断未授权库存 |
| VLB | 包装/素材所需样品和时点 | 寄运可行性、交期、特殊货物约束 | 决定内容机制 |
| CIG | 退货/服务需求和客户承诺约束 | 可履约承诺、退货路径 | 执行补偿/触达 |
| PLCO | 页面承诺和可购买状态请求 | ATP/CTP、配送、退换和降级线 | 修改页面 |
| AAMO | 消耗/放量需求曲线 | 可履约广告上限和批次衔接 | 修改预算/出价 |
| CAPM | 寄样、发布时间、样品需求 | 寄样状态、货权、失败恢复 | 决定合作合同 |
| MBCM | 活动需求、日历和情景 | 容量上限、服务风险和退出路径 | 改写活动策略 |
| F01/ECAE | 经 D07 合同验证的增量贡献、适用范围、有效期与重算触发 | 消费者回执、接受/拒绝/降级和库存排序资格 | 将预测或缺失值升级为因果证据；改写路线、分配、补货、履约 |

## 接受与冲突

接收方验证对象、货权、单位、状态时点、能力版本、证据等级和哈希后才可 `validated`。`proposed` 不得进入 ATP、补货或调拨。冲突按安全/合规、货权、数量守恒、主权、时点、证据和尾部风险裁决。

部分失败只污染依赖结论：承运商接口失败时保留已核验库存；PLCO 不可用不改变 ATP，但页面承诺标为未确认；AAMO 不可用不改变补货模型，只把广告需求协同降级。

F01/ECAE 回执缺失、未签、过期、范围不匹配或触发失效时，只撤销增量排序资格并请求重算；增量值保持 `unknown`，绝不填 0。F01 不可用不改变 LIFD 对基础保护、数量守恒和现有库存事实的判断，但共享池的精确边际分配保持 `inconclusive`。消费者回执只证明本地合同执行，生产双轨和独立所有者接受必须分别留证，不能由 fixture 代替。

## 结果回填

回填接受版本、实际下单/调拨、实际发运/到货、损耗、容量、服务、全成本、缺货/积压、退出回收、偏差原因和下一重算触发。货权、批次、需求、交期或能力版本变化时撤销陈旧承诺并只重算受影响闭包。
