# LIFD 专业深度治理

## 决策对象与不可省略项

物流库存决策锁定 SKU/变体/批次、货权、国家、仓、路线、渠道、状态时点、需求窗、补货窗、承诺窗和模型版本。短答只压缩展示，不得省略数量守恒、尾部交期、能力、全成本、反对证据、不行动、成功、停止、回滚和海外库存退出。

## 证据与输入质量

| 等级 | 最低条件 | 允许动作 |
|---|---|---|
| Q0 | 对象、单位、货权、库存或合规不可用 | 阻断并补数 |
| Q1 | 报价、计划或外部基准为主 | 方向筛查 |
| Q2 | 关键量可对账，缺口可由区间覆盖 | 条件方案和翻转阈值 |
| Q3 | 状态、成本、交期分布、能力和需求误差可复算 | 具体数量与承诺 |

证据标记 `observed/authorized/derived/inferred/causal`。报价、平均交期、计划到货和系统可售不得冒充真实能力、尾部服务或物理库存。

## Hard Gates

| Gate | 必须核验 | 失败动作 |
|---|---|---|
| G0 合规安全 | 禁运、危险、召回、证件、清关 | 立即阻断 |
| G1 货权批次 | owner、批次、状态和可售性守恒 | 冻结调拨/处置 |
| G2 数量守恒 | 期初+入库−出库−损耗=期末 | 禁止补货/ATP |
| G3 需求证据 | 缺货截尾、异常、误差和生命周期 | 只给区间测试 |
| G4 交期服务 | 分布、P90/P95、波动来源和承诺覆盖 | 降级承诺 |
| G5 能力 | 路线、仓容、吞吐、尾程和备选 | 限量或切换 |
| G6 经济现金 | 总相关成本、峰值现金、下行情景 | 阻断负边际扩量 |
| G7 退出 | 回收、退供、转仓、清算和合规销毁 | 禁止无退出补货 |

## 必算量与失败断言

- 补货必须计算预测分布、保护期、服务分位数、安全库存、ROP、在途、MOQ/箱规、容量、现金和批次衔接。
- ATP/CTP 必须分离物理库存、合格可售、保护量、已分配、在途可信度和能力日历。
- 网络路线必须比较落地全成本、尾部分位、损失概率、恢复时间和替代容量。
- 平均销量不得直接作为缺货期间真实需求；平均交期不得替代 P90/P95。
- 库存不可对账、交期无分布、成本缺失、合规未知或约束不可行时不得输出精确补货/承诺。
- “最优”必须保留低成本、平衡、高服务/高韧性候选及不行动基线。

## 压力场景、动作与回填

至少重算需求下行/上行、交期 P90/P95、路线或仓容损失、汇率/费率上行、退货上升、货权/合规阻断和系统库存延迟。不可补偿 Gate 先于加权评分。

关键数量必须由脚本计算并留输入/输出哈希。动作写明对象、数量、最晚日期、责任域、批准、成功、停止、回滚、升级和退出。结果回填实际需求、到货、损耗、服务、成本、缺货/积压、预测偏差、承运商/仓库偏差和下一重算触发。
