# AAMO 专业深度治理

## 决策对象与不可省略项

广告判断必须锁定账户、活动、广告组/广告集、广告/素材、定向/查询、国家、币种、时区、版本、四轴、生命周期、归因窗、订单成熟窗和 `as_of_time`。短答只压缩呈现，不得省略数据门、利润门、反对证据、动作幅度、成功、停止、回滚和结果回填。

## 证据与结论等级

| 等级 | 可证明内容 | 动作上限 |
|---|---|---|
| S0 `unverified` | 用户描述或未核验截图 | 只列补证，不给数量动作 |
| S1 `observed` | 平台可见配置、展示、点击等观察事实 | 诊断候选或可逆修复 |
| S2 `authorized` | 授权后台、订单、成本和追踪明细 | 条件预算/出价试验 |
| S3 `derived` | 确定性脚本重算、口径和哈希完整 | 有上限的本域动作 |
| S4 `causal` | 合格实验/准实验、识别诊断和区间 | 受利润与容量约束的放量 |

平台报表只能证明平台口径。成熟利润还需退款、取消、拒付、优惠、平台费、商品与履约成本；增量需要合格反事实。`inferred` 必须单列，不得伪装成 S2—S4。

## Hard Gates 与动作上限

| Gate | 通过证据 | 失败动作 |
|---|---|---|
| G0 对象/权限 | 账户、站点、产品、版本和授权可核验 | 阻断正式动作 |
| G1 资格/合规 | 广告资格、政策、商品与素材许可 | 停止或修复资格 |
| G2 测量 | 事件、去重、归因窗、Consent、订单对账 | 只做交付诊断 |
| G3 成熟经济 | 成熟收入、全成本、币税和退款窗 | 禁止利润型放量 |
| G4 边际识别 | 相邻预算档或响应曲线及区间 | 禁止用平均效率放量 |
| G5 库存/承接 | ATP/CTP、配送、页面和事件链通过 | 限制消耗或阻断 |
| G6 因果 | 分配、曝光、污染和反事实可接受 | 禁止增量声明 |

`unknown` 不得当作 `pass`。任一不可补偿 Gate 失败时，评分、ROAS 或资金充足均不能覆盖。

## 失败断言

- 低展示不等于出价低；必须依次排除资格、受众/查询、素材、预算节奏、事件、库存和页面。
- Quality Score、相关性诊断或素材评分不是公开的完整竞价公式。
- 平台归因订单、New-to-brand、品牌光环或浏览归因不等于增量订单。
- 账户平均 ROAS/ACoS 不得替代商品、查询、版位和相邻预算档边际贡献。
- 未成熟订单、断裂追踪、混合币种/时区、缺成本或区间跨零时必须 `inconclusive`。
- 自动化产品的可见设置不得被描述为完整黑箱算法；未知机制用可控输入、可观测输出和证伪实验处理。

## 反事实、压力场景与回填

至少比较不行动、维持、增量、降量/暂停和重建；保留自然蚕食、品牌词、季节、促销、学习期、页面/库存变化和归因窗错配。压力场景同时覆盖转化率下行、退款上行、CPC/CPM 上行、回传延迟、库存收缩和学习重置。

动作必须由确定性脚本输出并保存输入/输出哈希、模型版本和币税口径，写明对象、幅度、责任人、审批、观察窗、最大损失、成功、停止和回滚。回填真实花费、曝光、成熟订单、成熟贡献、增量、边际结果、偏差原因和下一次重算触发。
