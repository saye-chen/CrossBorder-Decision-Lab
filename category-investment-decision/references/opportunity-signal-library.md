# CIDM 机会信号库（OSL-v1）

本库是外部研究方法的 clean-room 内部规格。外部工具只提供候选证据；CIDM 保留资本进入、追加、收缩和退出主权。任何信号只允许生成候选或验证计划，不得直接加分、备货或投资。

## 八类规范信号与17种战术归并

| 内部信号 | 纳入的外部战术 | 必须验证的反例或替代解释 |
|---|---|---|
| `NEW_PRODUCT_BREAKOUT` | 新品快速爆发、隐形爆款、高新品占比 | 父子体伪新品、评论继承、促销污染、品牌流量、低存活 |
| `DISTRIBUTED_KEYWORD_DEMAND` | ABA高增长趋势词、流量分散词、标题密度 | 季节/事件词、低购买意图、品牌词、混合意图、语义覆盖 |
| `RESOLVABLE_PRODUCT_GAP` | 热销低评分、评论语义、低质量Listing | 服务/物流主因、用户误用、不可解物理限制、页面非因果 |
| `MARKET_ENTRY_STRUCTURE` | 低品牌垄断、高新品占比 | 碎片化价格战、广告垄断、高进入低存活、子品牌拆分 |
| `ECONOMIC_FEASIBILITY` | 高毛利轻小、高客单长尾、本土溢价 | 平均售价假利润、退货/质保/认证/服务溢价、规模上限 |
| `TRAFFIC_REPLICABILITY` | 自然流量反查、低质量Listing | 品牌词、推荐/站外误归因、单期工具估算、品牌资产 |
| `VALIDATED_SUPPLY_GAP` | 变体缺口、FBM拦截、本土溢价 | 无需求空白、大件/危险品/定制限制、库存复杂度 |
| `SEASONAL_PREPOSITIONING_WINDOW` | 季节前置布局 | 单年事件、错过最晚下单日、晚到仓、无库存退出路径 |

外部仓库宣称16种，审计实际识别17种；“高新品占比”同时参与新品持续性与市场结构，但共享同一来源家族时只能提供一次独立置信度。

## 通用硬门

- 对象主键缺失：执行失败。
- 时间窗缺失：`inconclusive`。
- 原始证据ID缺失：`blocked`。
- 只给支持证据：最高低置信度。
- 未知值保持 `unknown`/`None`，绝不补0。
- 利润、合规、IP、安全或生命周期否决可覆盖全部支持信号。
- LC-1/LC-2 只输出验证动作，不产生批量备货。

每种战术的详细业务判定、公式和边界以《Amazon Sorftime Research MCP Skill 方法论汲取与优化实施方案》v1.3第6至22章为来源规格；代码不复制外部仓库实现。
