# 定价模型路由与商家原型

## 六维路由

每次先识别商业模式、定价目标、生命周期、价格对象、约束环境和证据能力。输出一个主模型、零到多个辅模型、经济下限、外部上限、推荐走廊、证据上限和重定价触发器。

## 18 类模型族

| 代码 | 模型族 | 适用 | 关键禁止条件 |
|---|---|---|---|
| P01 | 成本加成 | 稳定制造、简单批发 | 成本不全或需求高度弹性 |
| P02 | 目标毛利/贡献 | Marketplace、DTC、零售 | 漏掉按收入费用、退款或现金 |
| P03 | 保本/生存 | 冷启动、短期防守 | 作为长期价值或品牌价格 |
| P04 | 竞争参照 | 高透明同质商品 | 竞品不可比或非真实成交价 |
| P05 | 价值/WTP | 差异化、创新、定制 | 只有内部主观判断 |
| P06 | 弹性/利润优化 | 稳定历史或实验 | 数据稀疏、同期干预或突变 |
| P07 | 渗透定价 | 新市场、新品 | 无损失上限、提价或退出路径 |
| P08 | 撇脂/溢价 | 稀缺、首发、高 WTP | 价值未证明或快速可替代 |
| P09 | 心理价格点 | 消费零售展示 | 掩盖经济不可行或误导 |
| P10 | 版本/好更佳最佳 | 多规格、多价值层 | 版本差异不真实或自相蚕食 |
| P11 | 阶梯/合同 | B2B、批发、经销 | 高层利润补偿低层不可接受亏损 |
| P12 | 渠道价格瀑布 | 多渠道、经销 | 忽略返利、冲突或实际成交 |
| P13 | 订阅/耗材 | 留存与复购明确 | 用未验证留存放宽现金红线 |
| P14 | 库存/时效动态 | 季节、容量、易逝 | 无库存、需求或退出事实 |
| P15 | 清仓/回收 | 衰退、退市、翻新二手 | 未与持有、退供和处置比较 |
| P16 | 预售/定制 | 非标、按单生产 | 忽略失败、返工、交期和退款责任 |
| P17 | 套装/交叉补贴 | 组合、引流品、生态 | 附着率或增量无证据 |
| P18 | 拍卖/使用量/容量 | B2B、云服务、稀缺容量 | 计量、容量或分配规则不可审计 |

## 典型路由

- Amazon 标准品：P02 主模型，P04/P12 辅助。
- TikTok Shop 内容驱动：P02 主模型，P07/P17 辅助。
- Shopify 品牌：P05 主模型，P02/P09/P13 辅助。
- 批发经销：P11 主模型，P12/P01 辅助。
- 订阅耗材：P13 主模型，P17/P05 辅助。
- 定制预售：P16 主模型，P05/P01 辅助。
- 季节库存：P14 主模型，P15/P06 辅助。

未知商业模式返回 `UNKNOWN_MODEL_ROUTE`，只生成补证清单和经济底线，不强套最相近公式。

## 模型冲突

先应用法律、安全、现金和可避免成本下限，再按已批准定价目标确定主模型。辅模型只形成上界、下界或反证；不同模型结果不得平均。目标冲突提交 CIDM 或相应主权域裁决，PPFC 保留每个候选的经济后果。
