# PPFC 跨域合同、异常树与裁决边界

## 1. 合同目的

PPFC 接收其他业务域已经声明口径、时间、对象版本和证据等级的事实，重算价格、利润、保本线、资金峰值与现金回收约束；PPFC 输出的是 `proposed` 经济约束，不是广告、物流、达人、营销、Listing 或投资动作指令。接收域必须显式接受、拒绝或要求重算，任何交接都不得自动外写。

## 2. 字段级交接矩阵

| 业务域 | PPFC 可接收 | PPFC 可返回 | 禁止替代的主权 |
|---|---|---|---|
| CIDM | 投资批次、资金上限、目标回收期、退出条件 | 可承受进货价、现金峰值、回收期、退出经济阈值 | 投资放行、组合配置 |
| CIM | 竞品价格、促销、容量与时点证据 | 价格走廊敏感性、竞争价格下的利润风险 | 竞品真实性与竞争判断 |
| VLB | 内容产能、制作与授权成本、自然/付费用途 | 单素材可承受成本、回收门槛 | 创意机制与内容选择 |
| CIG | 留存、退款、复购、CLV 输入及置信度 | CAC/回收期/客户贡献约束 | 客户策略、服务补偿 |
| AAMO | 花费、归因订单、增量状态、流量结构 | 保本 ROAS/ACOS/CAC、边际预算护栏 | 归因裁决、投放启停与扩量 |
| LIFD | 路线、计费重、费率、库存损耗、交付时点 | 到岸成本上限、路线成本敏感性、现金占用 | 路线选择、补货与履约动作 |
| PLCO | 平台费率、支付费、折扣、转化与退款口径 | 可售价格走廊、最低成交价、促销护栏 | Listing、Offer 与页面动作 |
| CAPM | 样品率、佣金、坑位费、授权费、达人归因状态 | 单样品投资、佣金上限、达人保本门槛 | 达人选择、合同与寄样放行 |
| MBCM | 活动资源、促销机制、渠道组合、品牌目标 | 活动贡献门槛、组合预算与价格红线 | 品牌、活动与营销编排 |

未来专业域只能通过同一信封扩展；扩展字段必须命名空间化，不能绕过对象、单位、币种、税口径、双时间和证据血缘。

## 3. 异常树与默认动作

1. 身份与版本：对象、批次、SKU、国家、平台或版本不一致 → `blocked`，禁止合并。
2. 单位/币种/税/时间：单位不可换算、汇率或税口径缺失、有效期冲突 → `blocked`；保留不受影响的同口径结果。
3. 缺失/过期/歧义参数：无规则、规则过期、同优先级冲突 → `inconclusive` 或 `blocked`；禁止静默使用默认值。
4. 对账异常：订单、成本、库存、现金或报表不守恒 → 按差异重要性降至 DQ0–DQ2，并降低动作上限。
5. 模型与场景：路由未命中、模型不适用、样本外极端情景 → 仅允许压力测试，不得给执行价格。
6. 现金与偿付：利润为正但现金峰值超过额度、回收晚于截止日 → 现金红线优先，状态 `blocked`。
7. 归因与增量：广告/达人/营销仅有归因值而无增量证据 → 可算归因利润，不得声称增量利润。
8. 工具或局部域失败：保留已验证且相互独立的结果，失败部分进入异常报告；整体动作上限取最严格值。
9. 权限与外写：任何外部下单、改价、调预算、寄样、签约或资金动作请求 → 一律拒绝并交还主权域。

## 4. 冲突裁决顺序

硬性合规、偿付和现金红线优先；来源域拥有其业务事实和业务动作主权；PPFC 拥有确定性经济重算及经济约束结论；接收业务域拥有是否接受并转化为动作的最终主权。旧结论不得覆盖更新对象版本，新结论必须 `supersedes` 旧版本并保留血缘。

## 5. 部分失败与恢复

`valid_retained_outputs` 必须列出仍可使用的对象、字段、口径和有效期；`failed_fields` 必须列出失败原因与责任域。动作上限依次为 `analysis_only < controlled_test < reversible_action < human_approved_execution`。任何 P0、身份冲突、现金红线或关键费率缺失均把上限压至 `analysis_only`。恢复必须指定责任人、补证条件、重算触发器和截止时间。
