# 决策主链与专业模型

本文件是 D04 的专业推理手册。公式只在输入对象、单位、时间窗和适用性门一致时使用；模型输出是决策证据，不自动等于放行。缺失值不得按零处理，代理值必须声明来源、偏差方向和敏感性。

## 目录

1. 六类决定共同顺序；2. 供应商选择；3. 报价/BOM/Should-cost/TCO；4. 采购承诺；5. 产能与交期；6. 样品；7. FMEA；8. 测量系统；9. SPC/能力；10. 抽样；11. 批次；12. 质量成本；13. 可靠性；14. 交付；15. 恢复；16. 参数治理；17. 复杂组合；18. 禁止捷径。

## 1. 六类决定的共同顺序

所有决定按以下顺序执行：

1. 冻结对象、版本、时点和最终 owner。
2. 区分事实、供应商声明、假设、推断和专业意见。
3. 执行身份、主权、版本、证据、职责分离和外部动作硬门。
4. 执行该决定独有的专业机制与适用性检查。
5. 比较至少两个可行方案和不行动基线。
6. 计算正常、下行和尾部情景，不以均值覆盖红线。
7. 输出决定、限制、成功门、停止门、回滚、恢复和复审时间。
8. 记录 evidence/calculation/decision ledger 与消费者响应。

状态只能是 `validated`、`blocked`、`inconclusive`、`not_computable` 或 `recovery_required`。证据缺失导致无法判断时不得用保守数字伪装成 `validated`。

## 2. 供应商选择

### 2.1 必查机制

- 身份链：签约方、收款方、开票方、实际工厂和受益所有人是否一致或已解释。
- 制造场所：地址、产线、设备、班次、许可范围和审核对象是否匹配。
- 供应网络：分包、关键物料、专用模具、关键设备、公用工程和地区节点是否披露。
- 能力：人员、设备、节拍、良率、换线、维护、瓶颈和爬坡证据。
- 质量历史：严重缺陷、逃逸、客诉、召回、重复问题和 CAPA 有效性。
- 商业韧性：MOQ、账期、交期、价格有效期、索赔、退出和资料/模具权属。
- 组合相关性：多个供应商是否共享工厂、次级供应商、物料、模具或地区风险。

### 2.2 硬门与评分边界

主体无法确认、未披露转包、关键安全红线、证据不可追溯、职责冲突或关键能力未证明时直接阻断。通过硬门后才允许多目标比较。

综合评分只能用于已通过硬门的候选排序。推荐输出 Pareto 前沿或分项向量，不将质量、交付、成本和韧性压成不可解释的单分。若使用权重，必须记录权重 owner、版本和敏感性；任何权重变化导致首选反转时标记 `weight_sensitive`。

### 2.3 集中度

供应份额 \(s_i\) 满足：

`HHI = Σ(s_i²)`，且 `Σs_i = 1`

计算至少在法定主体、实际工厂、关键物料和地区四个层级分别进行。一级供应商 HHI 低但共同依赖同一实际工厂时，真实冗余仍为单点。不能仅以名称数量证明多源。

### 2.4 首单暴露

首单上限取以下约束的最小值：

- 风险资本允许暴露；
- 已验证产能；
- 可检验和可隔离数量；
- 可承受质量损失；
- 可在恢复窗口内替代的数量；
- 准入意见覆盖的对象与市场范围。

输出主供、备供、分配上限、再资格触发器和退出门，而不是只输出“推荐供应商”。

## 3. 报价、BOM、Should-cost 与 TCO

### 3.1 报价标准化

同一基准币种下：

`标准化总额 = (单价 × 数量 + 额外费用) × 汇率`

`标准化单位成本 = 标准化总额 ÷ 数量`

报价必须绑定数量阶梯、币种、汇率时点、税费边界、贸易术语、包装、模具摊销、付款条件和有效期。不同 Incoterms、税口径或包装单位的报价不得直接比较。

### 3.2 BOM roll-up

单个组件考虑损耗后的单位贡献：

`组件成本 = 用量 × 单价 ÷ (1 - 损耗率)`

`BOM 成本 = Σ组件成本`

损耗率必须满足 `0 ≤ scrap < 1`。BOM 版本、替代料、生效批次和自制/外购边界必须明确。缺少任一关键组件不得把成本当作完整 BOM。

### 3.3 Should-cost

Should-cost 用于解释成本结构和谈判，不是供应商真实成本。建议拆分：

- 直接材料：净用量、正常损耗、回收价值；
- 直接人工：标准工时、有效工资和效率；
- 机器/工序：机时、能源、维护、工装与良率；
- 制造费用：可归属间接成本；
- 包装、测试、认证摊销和质量保证；
- 合理利润与风险溢价。

每一项标记 `observed/contracted/estimated/benchmark`。估算项必须给低、中、高情景；不得通过未知加成倒推出“精确”供应商利润。

### 3.4 TCO

采购总成本至少包括：

`TCO = 采购价 + 运输/清关接口成本 + 资金占用 + 检验 + 质量失败 + 延误 + 切换/退出 - 可回收价值`

D04 可以计算供应方案的成本影响，但正式价格利润和现金主权属于 D06，物流路线与库存处置属于 D07。跨域输入被拒绝时相关 TCO 字段失效并重算，不得保留旧值。

## 4. 采购承诺

采购承诺必须绑定当前规格/BOM、有效供应商状态、报价版本、数量/MOQ、币种、贸易边界、付款节点、承诺交期、质量协议、变更控制、索赔、模具/资料权属和退出条件。

最小门：

- `supplier_approval = passed`
- `capital_authority = passed`
- `cash_constraint = passed`
- `compliance = passed` 或适格且范围匹配的临时专业意见
- 规格、BOM、报价均为 current
- 外部执行请求为 false

承诺状态区分 `proposed/conditionally_committed/committed/blocked/superseded`。D04 只决定条件是否可接受，不代替用户签约、下单或付款。

## 5. 产能、节拍与交期

### 5.1 有效产能

`有效产能 = (可用工时 - 换线工时) × 单位小时产出 × 良率 × 开机率`

`产能缺口 = 有效产能 - 需求`

输入必须大于零且 `0 < 良率, 开机率 ≤ 1`。名义铭牌产能不能替代有效产能。多工序产能以瓶颈为上限，不能把各工序产能相加。

### 5.2 风险调整

需分别考虑：

- 设备故障与计划维护；
- 换线、首件和清线时间；
- 人员技能与班次缺口；
- 物料、模具、检具和公用工程约束；
- 爬坡曲线和良率学习；
- 返工占用与检验吞吐；
- 与其他客户共享的产能。

供应商口头承诺只支持候选情景，不能直接作为 verified capacity。

### 5.3 交期

`承诺交期 = Σ阶段时间 + 风险缓冲`

阶段至少分解采购、物料等待、排产、生产、检验、返工概率、包装和出厂准备。D07 拥有运输与入仓路线；D04 不把运输假设静默写入生产交期。

## 6. 样品批准

样品类型及证明上限：

| 类型 | 可支持 | 不可外推 |
|---|---|---|
| 概念样 | 外观/概念方向 | 工艺、量产质量和可靠性 |
| 工程样 | 功能与工程验证 | 稳定量产 |
| 签样 | 已签特征基准 | 未覆盖特征与未来变更 |
| 首件 | 指定设备/工艺首次结果 | 长期稳定性 |
| 试产样 | 受控小批过程结果 | 峰值产能和长期可靠性 |
| 留样 | 争议比对与追踪 | 未证明的代表性 |

最小门包括样品身份、来源工厂、规格版本、chain of custody、CTQ 覆盖、测量系统和失败 CTQ。任何材料、工艺、工厂、设备或检验方法变化都触发重新验证。

状态为 `under_test/conditionally_approved/approved/rejected/expired/superseded`。条件批准必须声明偏差、对象范围、截止时间和重新验证项。

## 7. FMEA 与控制计划

FMEA 的严重度、发生度、探测度均采用受控的 1–10 刻度：

`RPN = Severity × Occurrence × Detection`

RPN 仅用于优先级排序。严重度达到安全或法规红线时，即使 RPN 不高也必须硬阻断；不能通过降低发生度或提高可探测性稀释高严重度。

FMEA 必须连接：

- CTQ/特殊特性；
- 预防控制与探测控制；
- 控制计划；
- 检验方法与反应计划；
- owner、期限和关闭证据；
- 变更后的重新评价。

措施完成不等于风险关闭，需验证措施有效且后续批次没有重复发生。

## 8. 测量系统

先证明测量系统，后分析过程。基础比率：

`P/T = 研究变差 ÷ 公差`

一般锚点：

- `P/T ≤ 10%`：通常可接受；
- `10% < P/T ≤ 30%`：条件使用，需结合用途、风险和改进计划；
- `P/T > 30%`：通常不可接受。

若有过程变差，可计算近似：

`ndc = floor(1.41 × 过程变差 ÷ 研究变差)`

`ndc ≥ 5` 才具备基础区分能力；关键高风险特性可能要求更高。阈值是默认锚点，不是跨行业强制标准，必须记录来源与适用性。

还需检查分辨率、偏倚、线性、稳定性、重复性、再现性、校准、夹具和操作者。边界读数应考虑测量不确定度和 guard band。

## 9. 过程稳定与能力

### 9.1 稳定性

个体值与移动极差的简化估计：

`MRbar = mean(|xᵢ - xᵢ₋₁|)`

`sigma_est = MRbar / 1.128`

`UCL/LCL = center ± 3 × sigma_est`

控制界限来自过程数据，不是规格界限。超出控制界限、连续趋势、分层或其他特殊原因信号存在时，过程不稳定；此时禁止计算并解释 Cp/Cpk。

样本量不足、数据非独立、混合多产线/班次或测量系统失败时返回 `not_computable` 或先分层。

### 9.2 能力

在测量系统可接受、过程稳定、分布假设适用时：

`Cp = (USL - LSL) / (6σ)`

`Cpk = min((USL - μ)/(3σ), (μ - LSL)/(3σ))`

Cp 反映潜在离散，Cpk 同时反映偏心。单侧规格使用单侧能力；非正态数据应使用受控分布、分位数或非参数方法，并声明方法。不能机械使用 `Cpk ≥ 1.33` 跨产品放行；关键特性的门槛由风险、客户和适格标准决定。

## 10. 抽样、AQL 与批次放行

抽样决定必须绑定总体、批次、抽样方案 ID、检验水平、AQL/限值、缺陷类别、样本量 `n`、接收数 `Ac`、拒收数 `Re` 和随机抽样链。

基础规则：

- 严重缺陷采用零容忍硬门时，出现一个即拒绝；
- 一般缺陷仅在 `defects ≤ Ac` 时接受；
- 样本不具代表性、抽样链断裂或批次混杂时结论无效；
- 抽样通过不等于零缺陷，也不证明所有未抽单位合格。

零缺陷时仍可用“rule of three”给出近似 95% 上界：

`缺陷率上界 ≈ 3 / n`

存在缺陷时本实现给出保守近似：

`缺陷率上界 ≈ min(1, (defects + 3) / n)`

正式使用更精确区间时需声明二项分布方法与置信水平。AQL 是方案参数，不是允许供应商持续生产某一缺陷率的质量目标。

## 11. 批次、数量守恒与逃逸风险

批次放行必须绑定生产放行、规格/BOM、工厂、产线、原料批次、工单、检验批、偏差和决定版本。

`投入 = 合格 + 不合格 + 返工 + 报废 + 在制 + 已解释差异`

不守恒时不得正式放行。返工品必须有返工指令、重新检验和次数/性能限制。让步接收必须由适格 owner 批准，并声明客户、合规、可靠性和追踪影响。

输出状态：

- `released`
- `conditionally_released`
- `quarantined`
- `rework_required`
- `rejected`
- `scrapped`
- 已发运后发现风险则进入 `recovery_required`，召回仅作为跨域建议

## 12. 质量成本

`COQ = prevention + appraisal + internal failure + external failure + recall`

五项均为必填，缺失不得按零。内部失败包括报废、返工、停线和复检；外部失败包括退货、索赔、客户支持、品牌和渠道损失；召回单列以避免被普通售后稀释。

质量成本用于比较预防、检验和失败代价，不意味着“花钱即可接受安全红线”。尾部责任、长期声誉和法律损失无法可靠量化时应定性列为限制，而不是省略。

## 13. 可靠性

观测失效率：

`failure rate = failures / test hours`

有失效时：

`observed MTBF = test hours / failures`

零失效不证明零风险。简化近似 95% 失效率上界：

`upper rate ≈ (failures + 3) / test hours`

可靠性结论必须说明任务剖面、应力、样本、删失、失效定义和环境是否代表真实使用。加速测试外推需要适用的物理模型和参数；不能只因测试时间长就直接等同现场寿命。

## 14. 交付可靠性

`OTIF = 按期足量订单数 / 总订单数`

必须冻结“按期”和“足量”的容差、承诺日期版本、订单拆分与供应商责任边界。均值 OTIF 应配合延期分布、尾部延误、旺季表现和恢复时间。取消订单、客户变更和供应商延期需分开归因。

## 15. 恢复、CAPA、切换与退出

事故顺序：

1. 冻结新增暴露；
2. 确定受影响对象、批次、订单、市场和已发运范围；
3. 隔离、停产、停发并保存证据；
4. 建立临时遏制和责任 owner；
5. 验证根因而非只接受供应商陈述；
6. 比较返工、补货、替代、切换、退出和不行动；
7. 验证 CAPA 有效性及重复发生；
8. 回填 D01、D03、D05、D06、D07、D13 和 ERDG。

恢复方案按可行性先过滤，再比较不可恢复损失、恢复天数、残余风险、现金和客户影响。最低损失方案若违反安全、准入或质量硬门仍不可选。

已承诺、生产中、不可逆或已发运动作不能“删除决定”解决，必须进入 `REALITY_RECOVERY`，核对沉没成本、可回收价值、批次范围、客户暴露和 owner 再批准。

## 16. 校准与参数治理

所有阈值记录：

- 参数名、单位和适用对象；
- 来源、发行方和证据等级；
- 国家/平台/产品/客户范围；
- 版本、生效、核验、到期和替代关系；
- owner、批准链和利益冲突；
- 默认值、允许区间和敏感性；
- 变更后的重算范围与回滚版本。

本文件中的 10%、30%、ndc 5、3σ、1.128 和 rule-of-three 是通用分析锚点，不替代适格行业标准、客户要求、法规或经过批准的企业标准。冲突时保留双方、升级 owner，未解决前 fail closed。

## 17. 复杂场景组合

复杂场景不得拆成互不影响的独立提示。至少建立以下传播链：

- 工厂未披露 + 三个候选共用关键物料 → 身份门失败、冗余失效、首单暴露下降；
- 材料替换 + 旧签样 + 旧报告 → 样品失效、重新验证、生产与批次放行阻断；
- 过程漂移 + 抽样偶然通过 → 稳定性优先，禁止用抽样结果覆盖失稳；
- MSA 不合格 + 边界读数 → 结论 `not_computable`，要求测量恢复；
- 超产能 + 已承诺 + 旺季 → 新承诺阻断，既有动作进入现实恢复；
- 关键缺陷 + 已发运 + 客诉聚集 → 批次追踪、停发、召回评估与客户域联动；
- CAPA 文档完整 + 后续复发 → 有效性失败，不得关闭恢复；
- D05/D06 消费者拒绝部分字段 → 只保留独立制造事实，经济或准入依赖字段失效并重算。

## 18. 禁止的推理捷径

- 不以最低价自动选供应商。
- 不以样品合格自动放量。
- 不以证书存在自动认定适用与符合。
- 不以 AQL 接受自动宣称零缺陷。
- 不在 MSA 失败或过程失稳时强算 Cpk。
- 不以一级供应商数量自动认定多源。
- 不以 CAPA 文件完成自动认定恢复有效。
- 不以自动化全绿自动认定真实经营成熟。
- 不替代 D01/D03/D05/D06/D07/D13 最终主权。
- 不执行签约、下单、付款、生产、放行、召回或外部消息。
