# 数据合同与自动化

所有输入保留 object_id、object_version、as_of_time、来源、单位、币种、事实/假设、缺失和零值语义。缺失不得填零，代理值声明偏差；同一事件幂等，版本冲突 fail closed。

真实联系人、报价、合同、检测和批次数据不得写入仓库。外部写入始终为 false；签约、下单、付款、放行、召回和消息必须由用户或获授权系统另行批准。临时目录只清理本任务所有权可验证的内容。

## 字段语义

每个数值字段必须携带单位、币种（如适用）、时间窗、来源和零值语义。区分：

- missing：未提供，不能填零；
- zero：已确认真实为零；
- not_applicable：不适用；
- unknown：当前无法确认；
- estimated：代理/估算，需偏差和敏感性；
- conflicting：存在多个不能调和的值；
- expired：曾有效但当前不可用。

字符串数字、千分位、括号负数、百分数和本地小数点格式必须规范化后再计算；无法确定单位或币种时 fail closed。

## 幂等与并发

同一事件以 idempotency key 去重。对象更新携带 expected_version：

- expected 与 current 一致：允许生成新版本；
- 已处理同一事件：返回既有结果；
- expected 落后：stale update，拒绝；
- 并发写入：保留冲突，不进行 last-write-wins；
- Rebase：显式声明基准变化和影响范围。

## 哈希与可重放

输入按稳定排序、明确编码和规范化数值生成 input hash；输出同样生成 output hash。ledger 保存模型运行时、参数版本、输入/输出哈希和状态。哈希证明内容未漂移，不证明来源真实或模型正确。

## 隐私与最小化

- 仓库 fixture 只能使用合成数据；
- 真实主体、联系人、账户、合同、报价和报告不得提交；
- 跨域只传完成决定所需字段；
- 报告展示可脱敏，但 ledger 保持受控引用；
- 权限终止、用途变化或保留期到期时停止继续使用；
- 不在日志、异常和临时路径泄露秘密。

## 自动化边界

脚本可执行确定性计算、Schema 校验、状态迁移、报告验证和评测；不得：

- 登录供应商平台并下单；
- 签署合同、付款或承诺资金；
- 直接向工厂发生产/放行指令；
- 发布召回或客户通知；
- 将合成结果标记为生产事实；
- 把网络失败当作“无风险”。

## 脏数据处理

解析前保留原始值和规范化值。典型反例：

- `"1,200 pcs"` 与 `"1.2k"`；
- `"10%"` 与 `0.1`；
- `USD 5` 与 `CNY 5`；
- 本地时间缺少时区；
- 同名供应商不同法定主体；
- 批次号在不同工厂重复；
- Excel 日期、空字符串、`N/A` 和零混用；
- 报告新版本覆盖旧版本但无修订链。

无法无损规范化时输出取证清单和阻断字段，不猜测。
