# 专业深度治理

任何决定必须绑定规范对象和版本、证据与反对证据、事实与假设、模型适用性、硬门、候选与不行动、下行情景、责任和时间、成功、停止、回滚、恢复、退出及结果回填。不得以关键词、文件长度、综合评分或测试数量替代专业机制。

六类主权决定必须分别证明供应商穿透、采购条件、样品证明上限、生产准备、批次血缘和事故恢复；重大安全、质量、欺诈或准入红线不可被成本优势补偿。

## 十项深度门

正式决定至少回答：

1. 对象、版本和时点是否唯一；
2. 事实、声明、假设和专业意见是否分开；
3. 该决定的独有机制是否完整；
4. 模型为什么适用，何时不适用；
5. 哪些硬门不可被收益补偿；
6. 至少两个候选和不行动基线是什么；
7. 正常、下行和尾部情景如何；
8. 哪些反证会使结论反转；
9. 成功、停止、回滚、恢复和退出如何执行；
10. 结果如何回填和校准。

## 机制而非篇幅

专业性不以行数、术语数或报告长度证明。每条重要声明必须至少连接以下两项，关键声明连接全部：

`reference rule → executable model/validator → positive test → independent failure → report field → evaluation case`

只有 reference、没有执行或失败证据的内容标为 `guidance_only`；只有脚本、没有 Agent 可读解释的机制标为 `underdocumented`。

## 校准纪律

默认锚点必须声明不是跨行业强制标准。正式参数记录来源、范围、版本、有效期、owner 和敏感性。真实结果持续偏离时重新校准，但不得用少量案例倒推阈值以美化历史表现。

## 专业意见边界

D04 可给制造、采购条件、生产和质量专业判断，但不能冒充律师、税务师、认证机构、财务 owner、物流 owner 或客户 owner。外部专业意见必须保留签发者、资格、范围、利益冲突和限制。

## 结论上限

- 数据 E0/E1：候选发现或阻断；
- E2：初步尽调、受限试验；
- E3：范围匹配的受控决定；
- E4：多批校准和成熟度证据；
- 无真实回放和独立复核：最高 L3 controlled pilot。
