# PLCO 专业深度治理

## 决策对象与不可省略项

页面决策锁定平台、国家、语言、店铺、Listing、SKU/变体、Offer、页面层、设备、流量、生命周期、`page_version_id` 和 `as_of_time`。短答不得省略 G1—G6、证据与反对证据、替代解释、具体方案、实验、成功、停止、回滚和结果回填。

## 证据与结论等级

| 等级 | 示例 | 动作上限 |
|---|---|---|
| E0 `unverified` | 用户转述、无版本截图 | 补证清单 |
| E1 `observed` | 当前页面、搜索结果、公开规则 | 诊断候选 |
| E2 `authorized` | 后台、流量、漏斗、审核和库存快照 | 可逆修复/实验 |
| E3 `derived` | 脚本重算、版本对比、守恒和哈希 | 具体改版 |
| E4 `causal` | 合格页面实验及护栏 | 受 Gate 约束推广 |

页面评分、竞品页面、前后变化和单次转化波动不得升级为因果。动态规则、字段和能力执行时重新核验。

## 六道 Hard Gates

| Gate | 必须核验 | 失败动作 |
|---|---|---|
| G1 身份/权限 | 店铺、Listing、SKU、页面版本和编辑权限 | 阻断发布 |
| G2 产品事实 | 规格、兼容、认证、证据和禁止宣称 | 删除/降级 Claim |
| G3 合规/权利 | 平台政策、法律、图片/文案/评论权利 | 阻断相关素材 |
| G4 Offer/经济 | 价格、优惠、利润、资格和展示一致 | 不得以页面掩盖经济问题 |
| G5 库存/履约 | ATP/CTP、配送、退换、容量和承诺 | 限制可购买承诺 |
| G6 测量版本 | 流量、设备、时间窗、事件和可比版本 | 只做诊断 |

`unknown` 不是 `pass`。违法、侵权、安全、伪造宣称、评论操纵、非法合并、不可复算计算和越权为 P0。

## 失败断言与具体交付

- 不曝光先分离资格、索引、类目/属性、查询相关性、Offer和库存，不直接归因标题。
- 不点击先核对流量意图、首屏/首图、价格配送和竞争环境，不用 CTR 单指标定因。
- 不加购/不成交必须分离页面承诺、选择复杂度、Offer、库存配送、购物车、结账和追踪。
- 页面改版必须给候选稿、逐槽图片 Brief、模块方案或路径改版，不得只给评分和最佳实践。
- 合并/拆分/迁移必须保存源/目标版本、评论/变体/Offer影响、传播确认和回滚路径。
- 资料不足时使用待批准 Claim 和结构化占位符，不得补造卖点、参数、认证或效果。

## 反事实、实验与回填

至少比较不改版、保守修复、推荐版和探索版，并保留流量错配、Offer/库存变化、设备差异、季节、竞争和测量污染。实验预注册主指标、护栏、样本/周期、MDE、版本冻结、污染检查、成功、停止和回滚；区间跨零只可 `inconclusive/test`。

具体优化由确定性脚本保存输入、输出、版本和哈希。动作写明页面槽位、责任人、审批、发布日期、传播确认、最大暴露、停止和回滚版本。回填实际曝光、点击、加购、购买、退货/投诉、利润护栏、设备/流量分层结果和下一重算触发。三例授权历史回放未完成前只允许 `controlled pilot`。
