# D05 双层主权与术语

状态：`blueprint_only`；不得把本文件注册为可调用 Skill。

## 双层主权

| 主题 | D05 商业流程主权 | 保留给适格专业主体 | D05 禁止输出 |
|---|---|---|---|
| 法律与法规 | 适用问题清单、证据资格、商业 Gate、阻断与升级 | 法律解释、法律有效性和正式法律意见 | `confirmed_legal` 或等价普遍合法声明 |
| 税务海关 | 事实包、情景口径、补证、商业动作上限 | 最终税务处理、申报、归类及适格意见 | `confirmed_tax`、最终 HS 或申报结论 |
| IP | 搜索范围、证据记录、风险初筛、升级和使用限制 | FTO、侵权或权利有效性法律意见 | `no_infringement`、`freedom_to_operate` |
| 认证测试 | 适用性候选、覆盖矩阵、文件核验和商业 Gate | 实验室结果、正式认证和证书签发 | `certified`，除非引用有效签发记录且明确签发者 |
| 平台准入 | 当前规则证据、材料清单、商业准备状态 | 平台正式审核和账号/商品批准 | 把历史通过或文件齐全写成当前平台批准 |
| Claim | Claim—证据—用途映射、限制和补证 | 需要资格或法定授权的专业结论 | 超出证据、对象、国家、平台、媒介或时间窗的许可 |
| 事故恢复 | 冻结范围、影响闭包、复核、整改和恢复 Gate | 法定通知、正式召回和专业责任判断 | 自动执行通知、下架、召回或申报 |

## 规范术语

| 术语 | 定义 | 不等于 |
|---|---|---|
| `market_access_gate` | 对具名对象、范围、用途和时间窗的商业继续/限制/阻断决定 | 普遍合法或政府批准 |
| `compliance_action_ceiling` | 当前证据允许的最高商业动作等级 | 风险概率或专业结论 |
| `claim_use_boundary` | Claim 在具名对象、媒介、受众、市场和时间内的允许范围 | Claim 绝对真实或永久有效 |
| `professional_review_routing` | 将明确问题和事实包交给所需资格、授权与辖区的专业主体 | D05 自行提供意见 |
| `professional_review_request` | 待外部适格主体回答的结构化请求 | 已取得专业意见 |
| `professional_opinion_receipt` | 对外部意见身份、范围、适用性和限制的接收记录 | D05 签发的意见或自动批准 |
| `compliance_recovery` | 失效、事故或整改后的冻结、复核、重算与恢复流程 | 删除历史阻断或恢复外部动作 |
| `screening finding` | 有限来源和范围内的初筛发现 | 未发现风险、确认合规或 FTO |

## 结论上限

没有适格专业意见时，D05 可以输出 `screening`、`evidence_required`、`professional_review`、`blocked` 或限定条件的商业准备建议；不得输出保留专业结论。即使存在专业意见，D05 也只能在意见的资格、辖区、对象、用途、时间和限制范围内形成商业 Gate。

## 冲突处理

- 专业意见之间冲突：保留双方，停止升级，交有权责任人复核；
- 官方规则与平台规则冲突：分别记录法律准入和平台运营影响，不互相替代；
- 商业 owner 要求越过红线：保持阻断并升级，不以收益抵消；
- D05 与其他专业域冲突：各域保留自己的事实和主权结论，只冻结依赖字段；
- 自动化结果与适格意见冲突：自动化结果降级为诊断线索，不覆盖专业意见，但意见本身仍须通过适用性检查。
